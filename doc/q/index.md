# q

- [`clap.q`](clap.md) — A lightweight Q/KDB-X module for parsing command-line arguments in a structured and type-safe way.
- [`dbm.q`](dbm.md) — A modernised version of the original KX `dbmaint.q` script used for database maintenance.
- [`fs.q`](fs.md) — Functions for performing common file system operations.
- [`math.q`](math.md) — Mathematical functions.
- [`unit.q`](unit.md) — Unit testing framework.
